# Astro Review Standards

## Review order

1. Astro suitability and scope
2. SOP traceability
3. rendering and hydration
4. structure and ownership
5. content/API/CMS boundaries
6. security and privacy
7. i18n, SEO, and accessibility
8. performance
9. TypeScript and testing
10. styling refinements

## Finding levels

- Critical: blocks merge
- Important: should be corrected before completion unless explicitly accepted
- Optional: non-blocking refinement

## Required review output

```md
## Verdict
Ready / Ready with minor fixes / Needs changes / High risk

## Critical issues

## Important improvements

## Optional refinements

## Validation status

## Documentation drift

## Final recommendation
```

Reviewers must identify exact files and contracts where possible and must not recommend broad rewrites without a demonstrated problem.
