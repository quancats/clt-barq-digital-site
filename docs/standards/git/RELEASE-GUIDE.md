# Release Guide

## Purpose

Define release readiness for applications.

## Release checklist

- [ ] All critical issues resolved.
- [ ] Milestone acceptance criteria met.
- [ ] API contracts updated.
- [ ] Database migrations reviewed.
- [ ] Frontend routes and SEO reviewed if applicable.
- [ ] i18n checked.
- [ ] Filament admin flows checked if applicable.
- [ ] Tests pass.
- [ ] Environment variables documented.
- [ ] Deployment steps documented.
- [ ] Rollback notes documented.
- [ ] Changelog updated.
