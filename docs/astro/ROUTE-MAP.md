# Route Map

Feature IDs: FEAT-PLATFORM-001, FEAT-PLATFORM-002, FEAT-PLATFORM-003, FEAT-PLATFORM-004, FEAT-PLATFORM-006, FEAT-CONTENT-001

See [FEATURE-BASELINE.md](FEATURE-BASELINE.md) and [DECISIONS.md](DECISIONS.md) for starter Feature IDs and ADRs.

Astro config: `output: 'static'`, `trailingSlash: 'always'`, `build.format: 'directory'` (ADR-0016). Public HTML URLs keep a trailing slash. On disk, builds emit `…/index.html` under `dist/`. Hosts must serve `/path/` from `/path/index.html` and 301 `/path` → `/path/` (platform-neutral; no vendor host config in the template). Prefetch is opt-in via `data-astro-prefetch` under `{ prefetchAll: false, defaultStrategy: 'viewport' }` (ADR-0018).

HTML routes keep full document navigation (MPA). Cross-document View Transitions are CSS-only (`FEAT-PLATFORM-006` / ADR-0012); there is no Astro `ClientRouter`.

URL helpers (`localizePath`, `stripLocalePrefix`, root redirect) and Playwright/unit coverage match `trailingSlash: 'always'`.
