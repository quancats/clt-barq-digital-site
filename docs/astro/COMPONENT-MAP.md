\* `BaseLayout` ships a tiny pre-paint theme bootstrap script (schema-versioned `site-theme` preference). It is not a Vue island and does not use `client:*` directives. `Analytics` injects third-party `gtag.js` in production per `PUBLIC_GOOGLE_ANALYTICS_MODE` when ID/enabled allow it; default mode is `opt-in` (TADR-0002); stored `denied` is always honored. Locale font selective preload follows ADR-0015. Shared chrome lives under `components/core/` and `components/layout/` (ADR-0018).

Shared Astro class variants live in `src/lib/ui/astroVariants.ts` (ADR-0009). Site-facing Astro/Vue markup uses Tailwind CSS 4 semantic utilities (`bg-background`, `text-foreground`, `text-muted-foreground`, `border-border`, `bg-muted`, `bg-primary`, `text-primary-foreground`, `bg-success`, `bg-warning`, `bg-danger`, `bg-info`, `rounded-xl`; brand scale via `bg-brand-*` only when a non-semantic tint is required) mapped from `@theme` / shadcn tokens (`theme.css` references Tailwind palettes + brand; not inline oklch) — not arbitrary `var(--surface-*)` / `var(--text-*)` aliases. Header chrome icon controls and CookieConsent actions target ~40–44px touch sizes; general shadcn density may remain denser on desktop. Astro cards use `ring-1 ring-foreground/10` to match Vue `Card`. Astro surfaces use `Icon` from `astro-icon/components` with `iconDir: 'src/assets/icons'` for local SVGs and Iconify packs for Lucide/Simple Icons; Vue islands keep `@lucide/vue`. Prefetch is opt-in (`data-astro-prefetch` / ButtonLink `prefetch`) under `{ prefetchAll: false, defaultStrategy: 'viewport' }`. MDX may import only components listed in `src/lib/content/rich-text/mdxAllowlist.ts`. Approved Vue islands: catalog + HeaderChrome only (do not replace HeaderChrome with Astro-only in baseline). Layout width: page/section-owned `Container` (ADR-0013). Feature IDs and starter decisions: [FEATURE-BASELINE.md](FEATURE-BASELINE.md), [DECISIONS.md](DECISIONS.md), [DECISIONS-INDEX.md](DECISIONS-INDEX.md).

## Shared component usage

| Component and import                                                                                    | Interface and composition                                                                                                                                                                                                 | Rendering                                                                                                                                                                    |
| ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@/components/layout/Header.astro`                                                                      | `locale`, optional `alternatePath` and `class`                                                                                                                                                                            | Astro links are usable from first render. It swaps to `HeaderChrome client:load` after hydration. The island takes `locale`, `defaultTheme`, `copy`, `paths`, `currentPath`. |
| `@/components/ui/sheet`                                                                                 | `Sheet` supports `open` and `update:open`. Compose `SheetTrigger`, `SheetContent side="end"`, `SheetTitle` and `SheetClose` in its default slot.                                                                          | Vue and Reka provide the focus trap, Escape and focus restoration. | `@/components/layout/Footer.astro`                                                                      | `locale`, optional `class`. Links are ordinary anchors. The privacy button opens the consent controls through the consent script.                                                                                         | Astro HTML with a small script for privacy.                                                                                                                                  |
| `@/components/astro/content/ButtonLink.astro`                                                           | `href`, optional `variant`, `size`, `class`, `prefetch`, `target`, `rel`. Put the link label in the default slot.                                                                                                         | Astro anchor. Avoid placing links or buttons in the slot.                                                                                                                    |
| `@/components/astro/content/CallToAction.astro`                                                         | `href`, `label`, optional `variant`, `external`, `prefetch`. | `@/components/astro/content/Card.astro`, `ArticleCard.astro`, `ArticleBody.astro` in the same directory | Card accepts `as`, `padding`, `class` and default content. Use independent sibling links for action and title.                                                                                              |
| `@/components/ui/combobox`                                                                              | Compose a trigger, named input, list, empty status and items in the default slot. | `@/components/ui/alert-dialog`                                                                          | `AlertDialog` accepts `open` and emits `update:open`. Compose a trigger, content, title, description, cancel and action.                                                                                                  | Vue and Reka manage modal focus. Use a static page link for essential actions before hydration.                                                                              |
| `@/components/ui/form`                                                                                  | `FormField name` exposes the field bindings through its scoped slot. Compose `FormLabel`, `FormControl`, optional `FormDescription` and `FormMessage`. Set `:has-description="false"` on controls without a description.  | Vue island. Existing callers with a description keep the default. FormMessage has a persistent live region and retains its error ID.                                         |
| `@/components/ui/alert`, `@/components/ui/stepper`                                                      | Alert accepts `variant` with title/description slots. Stepper accepts `v-model`, emits `update:modelValue` and exposes each item's `state` slot property.                                                                 | Use a static Astro notice for content-only messages. Use the Vue primitives for catalog compositions and live state.                                                         |
