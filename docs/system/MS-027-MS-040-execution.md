## Analytics reporting contract

| Event                                             | Trigger                                                                                   | Additional property                                               |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| `page_view`                                       | One explicit event after the configured consent permits analytics on the canonical origin | None                                                              |
| `bim_outbound`                                    | Activation of the official BIM product link                                               | None                                                              |
| `contact_action`                                  | Activation of a contact CTA or contact link                                               | None                                                              |
| `consultation_cta`, `demo_cta`, `partnership_cta` | Activation of the applicable request CTA                                                  | None                                                              |
| `lead_accepted`                                   | One conversion per accepted form page after HTTP 202                                      | `lead_type` from `general`, `consultation`, `demo`, `partnership` |

Common properties are the generated canonical URL with query and fragment removed, the fixed page locale, and an empty referrer. The consent loader is eligible only for a production profile, configured canonical origin and valid measurement property. Default behavior waits for opt-in. Denial is checked at event time. The launch property owner must verify analytics consent text, disable automatic enhanced measurement and cross-domain tracking for this stream, and confirm reporting with approved test traffic. No analytics provider was contacted during the tests.

No hosted CI run, commit, push, merge, deployment, or MS-041 work was performed.
