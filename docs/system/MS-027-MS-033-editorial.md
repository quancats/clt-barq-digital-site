## Authoring and publication

- Define the knowledge hub using the `pages` translation key `insights` and approved localized sections. The hub shows the article, news and resource sections with approved entries in its locale.
- Define localized articles and news with a Markdown body, publication date, category, optional category label, optional tags and tag labels, and optional approved author key. Category and tag keys generate localized static listings. Sort order is newest publication first. The existing starter article fixtures are served from the legacy preview routes under the local environment.
- Use `products`, `services` and `solutions` for editorial related references. Resources can also reference approved `articles` and `news` in the resource locale.
- Place cleared PDFs under `public/downloads/`. Encode file language and opaque rights reference in the resource entry and keep the actual clearance with its owner. Empty lists and missing translations are withheld from generated routes.
- Record each approved revision and locale in the [publication register](MS-003-route-content-register.md). The source build uses those references to enforce publication status. [Collection contract](MS-005-content-publication.md)
