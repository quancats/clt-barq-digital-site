# Astro Definition of Ready

A milestone or issue is ready only when:

- [ ] Feature ID and milestone are present.
- [ ] Repository/application owner is clear.
- [ ] Astro is suitable for the requested work.
- [ ] Routes and page inventory entries exist.
- [ ] Content owner, source, schema, and freshness are documented.
- [ ] Rendering mode is approved.
- [ ] Locale, RTL, SEO, and locale font requirements are complete.
- [ ] Analytics/consent/legal scope is known (including GA4 disable path when analytics is in scope).
- [ ] Design references and component expectations are available.
- [ ] API/CMS contracts are approved where applicable (or explicitly out of scope / recipe-only).
- [ ] Hydration need is known or explicitly absent.
- [ ] Dependency and package-manager changes are identified and approved.
- [ ] Acceptance criteria and test expectations are measurable.
- [ ] Cross-repository dependencies are linked.
