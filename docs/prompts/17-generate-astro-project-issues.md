# Cursor Prompt — Generate Astro Project Issues

Read system docs and Astro project maps. Generate issues by milestone and dependency.

Each issue includes:

- title (issue name only; classify via GitHub Milestone / Labels / Issue Types)
- repository
- Feature ID
- milestone
- route/page IDs
- content/API dependencies
- scope and exclusions
- implementation tasks
- acceptance criteria
- locale/SEO/accessibility requirements
- tests
- docs updates
- dependencies and blockers

Separate Laravel/CMS issues from Astro issues while linking the same Feature ID.
Do not prefix titles with `[ASTRO]`, `[MS-…]`, `[FEAT-…]`, or type tags.
