# Cursor Prompt — Plan an Astro Informational Website

Plan only. Do not generate application code.

Input:

- business/project scope
- audiences
- brand/design inputs
- locales
- content source
- CMS/backend context
- deployment target

Create or update:

- Astro scope and suitability
- page inventory and route map
- content ownership
- CMS/API map
- locale and SEO strategy
- rendering matrix
- component taxonomy
- island candidates
- design tokens/system plan
- analytics/forms/legal map
- performance budget
- implementation milestones
- project issues

Do not assume Vue, SSR, a CMS, or a dependency unless required and approved.
