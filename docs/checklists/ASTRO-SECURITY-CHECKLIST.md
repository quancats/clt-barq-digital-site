# Astro Security and Privacy Checklist

- [ ] No secrets enter public/client bundles.
- [ ] External data is validated and narrowed.
- [ ] Rich text, HTML, links, media, and SVG are safe.
- [ ] Forms have server validation, abuse control, and minimal data collection.
- [ ] Logs exclude tokens and personal data.
- [ ] Analytics and third parties are approved; GA4 disable path works; consent-aware loading is used when legal scope requires it.
- [ ] Preview and staging are protected and non-indexable.
- [ ] CSP and platform security headers are reviewed (report-only before enforcement when GA/inline scripts are present).
- [ ] Dependencies and adapters have a security owner.
- [ ] Security exceptions are documented.
