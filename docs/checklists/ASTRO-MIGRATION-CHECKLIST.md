# Nuxt to Astro Migration Checklist

- [ ] Astro suitability is confirmed per route family.
- [ ] Routes, redirects, middleware, and SEO are inventoried.
- [ ] Components are classified as Astro Component, UI Primitive, Vue Island, Composite Pattern, script, retain, or remove.
- [ ] Shared Pinia/client state is reviewed.
- [ ] API and CMS layers are mapped.
- [ ] Locale and metadata parity is documented.
- [ ] Nuxt UI replacements follow the Astro replacement map (`shadcn-vue` / Astro / HTML).
- [ ] Nuxt UI is not retained as a permanent Astro dependency unless documented as a temporary migration exception.
- [ ] Dependencies and client code are reduced safely.
- [ ] Incremental milestones and rollback exist.
- [ ] Performance and SEO baselines are compared.
