# Astro Island Approval Checklist

- [ ] Interaction requires browser JavaScript.
- [ ] Native HTML/CSS was considered.
- [ ] An Astro Component or focused script was considered.
- [ ] Existing UI Primitive or Composite Pattern was inspected.
- [ ] State is cohesive in one Vue Island.
- [ ] Vue / shadcn-vue / Reka UI is already approved or proposed.
- [ ] Least aggressive Client Directive is selected.
- [ ] `client:load` or `client:only` is justified when used.
- [ ] JS failure fallback is defined.
- [ ] Accessibility, RTL, and Dark Mode behavior are defined.
- [ ] Client size is acceptable.
- [ ] Browser tests are planned.
