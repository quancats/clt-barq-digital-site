# Astro CMS Integration Checklist

- [ ] Content owner and publication lifecycle are clear.
- [ ] API/loader contract exists.
- [ ] Pagination/rate limits/timeouts are handled.
- [ ] Runtime schemas exist.
- [ ] Draft/private content is excluded.
- [ ] Locale and translation identity are explicit.
- [ ] Rich text and media are safe.
- [ ] Rebuild webhook and failure behavior are documented.
- [ ] Preview is protected.
- [ ] Astro does not duplicate backend business logic.
