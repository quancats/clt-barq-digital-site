# Astro Page Definition of Done Checklist

- [ ] Approved content is complete.
- [ ] All locales are complete.
- [ ] Route, status, canonical, and alternates are correct.
- [ ] Initial HTML contains primary content.
- [ ] Responsive and RTL are verified.
- [ ] Images/fonts are optimized (active-locale font preload only).
- [ ] Accessibility and keyboard checks pass.
- [ ] Hydration is absent or justified.
- [ ] Analytics/forms work without exposing sensitive data.
- [ ] Tests/build pass.
- [ ] Page inventory and changelog are updated.
