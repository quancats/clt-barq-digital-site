# Astro Feature Readiness Checklist

- [ ] Feature ID and milestone.
- [ ] Routes/pages affected.
- [ ] Content/API source and owner.
- [ ] Rendering mode.
- [ ] Locales, SEO, and locale fonts.
- [ ] Analytics/consent impact known when third parties are involved.
- [ ] Component/island boundary.
- [ ] No missing dependency decision (`docs/recipes/` vs baseline runtime).
- [ ] No fake runtime content assumed.
- [ ] Acceptance criteria.
- [ ] Tests and docs expected.
