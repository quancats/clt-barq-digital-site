# Cursor Command — Generate Project Issues

```text
Generate project issues from system documentation.

Do not write code.

Read system docs and create/update:
- docs/issues/PROJECT-ISSUES.md

Group issues by:
- milestone
- repository
- application
- Feature ID
- domain
- dependency order

Every issue must include:
- title (clear issue name only — no milestone/Feature ID/type prefixes; use GitHub Milestone / Labels / Issue Types for those)
- repository
- application owner
- Feature ID
- milestone
- type
- priority
- dependencies
- scope
- out of scope
- acceptance criteria
- docs updates
- tests/checks
- risks

Do not create vague issues like "build dashboard".
Do not encode MS/FEAT/type into the title.
```
