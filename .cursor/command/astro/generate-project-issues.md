# Cursor Command — Generate Astro Project Issues

Read approved system docs and Astro project maps. Generate issues grouped by milestone and repository dependency.

Each issue must include a clear name-only title (no `[ASTRO]` / milestone / Feature ID / type prefixes), repository, Feature ID, milestone, Page/Route IDs, content/API blockers, scope/out-of-scope, tasks, locale/SEO/accessibility/performance/security requirements, acceptance criteria, tests, docs updates, and dependencies. Classify milestone/type/priority with GitHub Milestone / Labels / Issue Types.

Create separate linked Laravel/Filament and Astro issues when both repositories must change.

## Required final output

- understanding of the requested scope
- standards and project documents consulted
- actions performed or findings produced
- validation completed or not run
- documentation affected
- blockers, risks, and required human decisions

## Safety

Do not invent missing product facts, content, endpoints, dependencies, editorial workflows, or deployment behavior. Stop at the appropriate gate when the task is not ready.
