Analyze routes, layouts, middleware, plugins, Nuxt UI components, composables/API, Pinia, i18n, metadata, SSR/static behavior, CMS integration, client code, and dependencies.

Classify each area as Astro Component, focused script, UI Primitive, Vue Island, Composite Pattern, retain in Nuxt, or remove/replace.
