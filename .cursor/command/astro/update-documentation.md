# Cursor Command — Update Astro Documentation

Analyze current code or Git changes. Do not modify application code.

Update only affected project documents: page inventory, route map, content ownership, rendering matrix, component/island inventory, API/CMS map, i18n/SEO matrix, performance budget, dependency/third-party register, deployment notes, changelog, and technical debt.

If code and docs conflict, record the gap and propose a corrective issue.

## Required final output

- understanding of the requested scope
- standards and project documents consulted
- actions performed or findings produced
- validation completed or not run
- documentation affected
- blockers, risks, and required human decisions

## Safety

Do not invent missing product facts, content, endpoints, dependencies, editorial workflows, or deployment behavior. Stop at the appropriate gate when the task is not ready.
