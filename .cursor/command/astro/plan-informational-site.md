# Cursor Command — Plan an Astro Informational Website

Plan and create project documentation only.

Use business scope, audience, brand/design, locale, content, backend/CMS, deployment, forms, analytics, legal, and SEO inputs.

Create suitability decision, Astro scope, page inventory, route map, content ownership, rendering matrix, i18n/SEO matrix, component/island plan, integration register, performance budget, deployment plan, milestones, and project issues.

Do not generate application code or assume Vue, SSR, CMS, or packages without approval.

## Required final output

- understanding of the requested scope
- standards and project documents consulted
- actions performed or findings produced
- validation completed or not run
- documentation affected
- blockers, risks, and required human decisions

## Safety

Do not invent missing product facts, content, endpoints, dependencies, editorial workflows, or deployment behavior. Stop at the appropriate gate when the task is not ready.
