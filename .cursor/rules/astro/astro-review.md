# Cursor Rule — Astro Review

## Review order

1. coherent scope and SOP traceability
2. Astro suitability
3. static/on-demand and Hydration decisions
4. structure and component ownership (`astro` / `ui` / `islands` / `patterns`)
5. shadcn-vue/Reka UI usage and Nuxt UI avoidance
6. content/API/CMS contracts
7. security and privacy
8. i18n, SEO, locale fonts, and accessibility
9. analytics/third-party env contract and consent scope
10. performance budgets and Client Directive cost
11. TypeScript, tests, build, and documentation
12. styling refinements; reject CDN font CSS and dual-locale font preload without cause

## Findings

Classify as Critical, Important, or Optional. Name exact files, routes, components, contracts, and validation evidence when possible.

## Restrictions

Do not begin with formatting while architecture is wrong. Do not recommend repository-wide rewrites without evidence. Do not praise generically. Do not modify code unless asked.

## Output

Verdict, blocking issues, important improvements, optional refinements, validation status, documentation drift, and final recommendation.
