هذه المقالة النموذجية توضح استخدام **MDX** ضمن مجموعة المقالات. فضّل Markdown العادي عندما لا تحتاج مكوّنات.

<Callout title="محتوى موثوق فقط">استورد مكوّنات Astro المعتمدة فقط. لا تضمّن جزر تفاعلية عشوائية أو HTML غير موثوق.</Callout>

## متى تستخدم MDX؟

- صناديق تنبيه أو أشكال أو كتل منظمة قابلة لإعادة الاستخدام
- تركيب خفيف لا يعبّر عنه Markdown بوضوح
- محتوى يكتبه مؤلفون موثوقون داخل المستودع
