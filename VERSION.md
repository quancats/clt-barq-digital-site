# Version

Project version metadata for the adopting application.

Versioning follows [Semantic Versioning 2.0.0](https://semver.org/spec/v2.0.0.html).
Release notes follow [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/) in [`CHANGELOG.md`](CHANGELOG.md).

This file is for the **project**, not the Astro starter template.
Template versioning: [`docs/TEMPLATE-VERSION.md`](docs/TEMPLATE-VERSION.md) / [`docs/TEMPLATE-CHANGELOG.md`](docs/TEMPLATE-CHANGELOG.md).

## Rules

- Bump `Version` here and in `package.json` together when releasing.
- Add a matching `## [X.Y.Z] - YYYY-MM-DD` section in `CHANGELOG.md`.
- Do not record template bootstrap work here; use `docs/TEMPLATE-CHANGELOG.md` and `docs/TEMPLATE-VERSION.md`.
- Do not replace this file with the governance format used by `docs/system/CHANGELOG.md`.
